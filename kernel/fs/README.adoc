= OFS — Ocero File System
:author: Vlad944467
:revdate: 2026-08-01
:lang: ru

**OFS** — простая 32-битная файловая система для Ocero OS.


== Структура

Суперблок — сектор 0
Корневая папка — сектора 2-3 (64 записи)
Данные — сектора 4+

== Команды

`ls` — список файлов
`cat <файл>` — показать содержимое
`write <файл> <текст>` — создать файл
`format` — отформатировать диск

== Пример

> ls
Files:
  hello.txt (22 bytes)

> cat hello.txt
Hello, Ocero OS!

> write test.txt "New file"
OFS: Wrote file: test.txt (22 bytes)

== Ограничения

Имя файла: до 32 символов
Файлов в корне: до 64
Размер файла: до 4 ГБ
