= OFS — Ocero File System
:author: Vlad944467
:revdate: 2026-08-01
:lang: ru

**OFS** — файловая система для Ocero OS.


== Структура

| Сектор | Что там |
|--------|---------|
| 0 | Суперблок |
| 1 | Резерв |
| 2-3 | Корневая папка |
| 4+ | Данные файлов |


== Команды

| Команда | Что делает |
|---------|------------|
| `ls` | Список файлов |
| `cat <файл>` | Показать содержимое |
| `write <файл> <текст>` | Создать файл |
| `format` | Отформатировать диск |


== Пример

```bash
> ls
Files:
  hello.txt (22 bytes)

> cat hello.txt
Hello!

> write test.txt "New file"
> ls
Files:
  hello.txt (22 bytes)
  test.txt (22 bytes)
