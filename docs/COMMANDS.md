# Команды BitOS-32

## 🖥️ Основные команды

| Команда | Описание | Пример |
|---------|----------|--------|
| `help` | Показать справку | `help` |
| `clear` | Очистить экран | `clear` |
| `reboot` | Перезагрузить систему | `reboot` |
| `shutdown` | Выключить систему | `shutdown` |
| `echo` | Вывести текст | `echo Hello` |
| `edit` | Открыть редактор | `edit` |
| `notes` | Показать сохранённую заметку | `notes` |
| `save` | Сохранить заметку на диск | `save` |
| `load` | Загрузить заметку с диска | `load` |
| `fetch` | Информация об ОС | `fetch` |

## 🎵 Мультимедиа

| Команда | Описание |
|---------|----------|
| `music` | Музыкальный плеер (бип, мелодия, тревога) |
| `datetime` | Цифровые часы |

## Оформление

| Команда | Описание | Пример |
|---------|----------|--------|
| `bgcolor` | Сменить цвет фона | `bgcolor 4` (красный) |

Цвета фона: `0`-черный, `1`-синий, `2`-зеленый, `3`-голубой, `4`-красный, `5`-пурпурный, `6`-коричневый, `7`-светло-серый, `8`-темно-серый, `9`-светло-синий, `A`-светло-зеленый, `B`-светло-голубой, `C`-светло-красный, `D`-светло-пурпурный, `E`-желтый, `F`-белый.

## Табличные команды (через `par`)

| Команда | Описание |
|---------|----------|
| `par help` | Справка по табличным командам |
| `par hello` | Приветствие |
| `par time` | Показать время |
| `par echo` | Вывести текст |
| `par calc` | Калькулятор (пример: `par calc 2+3`) |
| `par sleep` | Пауза (пример: `par sleep 3`) |
| `par bgcolor` | Сменить цвет фона |
| `par edit` | Открыть редактор |
| `par clear` | Очистить экран |
| `par type` | Узнать тип команды |

## 💾 Работа с диском

| Команда | Описание |
|---------|----------|
| `disks` | Показать найденные диски |
| `testdisk` | Проверить диск |
| `files` | Файловый менеджер |

## 📝 Примеры

```bash
# Сменить фон на красный
bgcolor 4

# Калькулятор
par calc 10+5

# Создать заметку
edit
/wq - сохранить
/q. - выйти
